# Як запускати TR-Brick прямо з GitHub (налаштування Mac, один раз)

Раніше нова версія приходила архівом, а кнопка **TR-Brick** на Робочому столі брала архів із Завантажень, збирала програму і запускала її. Тепер архівів немає: та сама кнопка сама завантажує найсвіжішу версію з GitHub, збирає тільки змінене і запускає.

Твої треки й записи в `~/Documents/TR-Brick` ця кнопка ніколи не чіпає.

Налаштувати треба один раз, це хвилин 10.

## Крок 1. Відкрий Термінал

Натисни **Cmd + Пробіл**, надрукуй `Terminal` і натисни Enter. Відкриється вікно, куди можна вставляти команди. Кожну команду нижче копіюй цілком, вставляй (Cmd + V) і тисни Enter.

## Крок 2. Встанови помічника GitHub

```
brew install gh
```

Зачекай, поки закінчиться (з'явиться знову рядок із `%` наприкінці). Якщо пише `brew: command not found`, напиши мені в проєкті, я поясню, як поставити Homebrew.

## Крок 3. Увійди в GitHub (один раз)

```
gh auth login
```

Він поставить кілька запитань. Стрілками обирай відповідь і тисни Enter:

1. **Where do you use GitHub?** → `GitHub.com`
2. **What is your preferred protocol for Git operations?** → `HTTPS`
3. **Authenticate Git with your GitHub credentials?** → `Yes`
4. **How would you like to authenticate GitHub CLI?** → `Login with a web browser`
5. Він покаже код із 8 знаків (наприклад `ABCD-1234`). Запам'ятай його і натисни Enter.
6. Відкриється браузер. Увійди у свій GitHub (якщо ще не увійшов), встав код, натисни **Continue**, потім **Authorize github**.
7. У Терміналі з'явиться `Logged in as slavasystem-bit`. Готово.

## Крок 4. Постав нову кнопку

Скопіюй цей рядок цілком (він довгий, це нормально) і встав у Термінал:

```
mkdir -p ~/TR-Brick && gh api -H "Accept: application/vnd.github.raw" "repos/slavasystem-bit/trbrick-daw/contents/tools/mac/launch.sh?ref=main" > ~/TR-Brick/launch.new && mv ~/TR-Brick/launch.new ~/TR-Brick/launch.sh && chmod +x ~/TR-Brick/launch.sh && ~/TR-Brick/launch.sh
```

Він завантажить нову версію кнопки і одразу запустить TR-Brick. Перший раз він завантажує всю програму з GitHub і збирає її, це може тривати кілька хвилин. Якщо кнопки **TR-Brick** на Робочому столі ще не було, вона з'явиться.

Якщо macOS спитає, чи дозволити Терміналу доступ до Робочого столу чи Документів, натисни «Дозволити».

Усе. Термінал можна закрити.

## Як користуватися далі

Двічі клацни **TR-Brick** на Робочому столі, як і раніше.

- **Звичайно** кнопка бере головну версію (main), тобто ту, на якій ти граєш.
- **Коли я готую зміну на перевірку** (pull request), кнопка покаже коротке меню:

  ```
  Which version to start?
     Enter  = main version (the one you play)
     12     = test pull request #12: ...
  ```

  Щоб перевірити зміну, надрукуй її номер (тут `12`) і натисни Enter. Щоб грати на головній версії, просто натисни Enter або зачекай 15 секунд, вона запуститься сама.
- Після перевірки наступного разу натисни Enter, і повернеться головна версія.
- **Немає інтернету** (наприклад, на виступі)? Кнопка скаже, що не змогла дістатися GitHub, і запустить версію, яка вже встановлена. Нічого не зламається.

## Якщо щось пішло не так

- `You are not signed in to GitHub` → повтори крок 3.
- `cmake is not installed` → у Терміналі: `brew install cmake sdl2`.
- `git is missing` → у Терміналі: `xcode-select --install` і погодься на встановлення.
- Будь-яка інша помилка → зроби знімок вікна Термінала (Cmd + Shift + 4, потім Пробіл і клік по вікну) і надішли мені в проєкті.

## Де що лежить (для довідки)

- `~/Documents/TR-Brick` → твої проєкти й записи (кнопка не чіпає).
- `~/TR-Brick/app` → програма і її збірка.
- `~/TR-Brick/repo` → чиста копія з GitHub (руками не змінювати).
- `~/TR-Brick/launch.sh` → сама кнопка; вона оновлюється сама, коли оновлюється головна версія.
