ЗАРАЗ (v44.58)
ПРОПОНУЮ: однаковий рядок [<] [назва ▾] [>] [HEAR] + хвиля
Ударні (Kick…Perc)блок KIT
<909>ALLMINE
▮▮▯ SAMPLE 2 / 3 · default for all steps
< > міняють весь кіт; картка SAMPLE: клік = наступний, правий клік = попередній (прихований жест); HEAR немає; «+ файл з Finder» немає; кинутий файл стирає kick_2, kick_3 і лягає в теку біля програми, не в проєкт.
KIT<909>
SAMPLE<kick_2.wav ▾>HEAR
KIT лишається як «пресет» усіх шести барабанів. SAMPLE такий самий, як у семплера: < > = сусідній семпл (варіанти цього кіта), назва відкриває браузер SAMPLES, HEAR слухає. Кинутий файл додається варіантом і копіюється в проєкт.
SAMPLERблок SAMPLE
<amen_break.wav>HEAR
Назва = список «samples/ біля проєкту» + пункти «MY SAMPLES (LIBRARY)...» і «+ ADD A .WAV / .AIF FILE...»; кнопки MINE немає (а в синта є); клік по порожній хвилі відкриває Finder; мітки слайсів: клік = додати, правий клік = прибрати.
SAMPLE<amen_break.wav ▾>HEAR
Той самий рядок. Порожня хвиля пише «Choose a sample» і відкриває той самий браузер. Мітки як точки в рядах: клік по порожньому = додати, тягнути = посунути, подвійний клік = видалити, правий клік = меню.
Бас · Synth2/3 · ChordENGINE > SAMPLE
<pad_C3.wav>HEARMINE
Як у семплера, але з кнопкою MINE; браузер має заголовок «MY SAMPLES: SAMPLER», хоча семпл іде в бас.
SAMPLE<pad_C3.wav ▾>HEAR
Той самий рядок. Заголовок браузера: «SAMPLE FOR: BASS».
Перехід перед брікомTRACK, меню переходу
TRANSITIONUP LIFTER ▾
Список вбудованих райзерів, унизу «MY SAMPLES...»; HEAR немає, хвилі немає, інше слово.
TRANSITION<UP LIFTER ▾>HEAR
Той самий рядок; вбудовані райзери стають ще одним джерелом у браузері (BUILT-IN).

Філ завжди починається точно на долі й закінчується рівно на першій долі наступної цеглинки (або такту). STRETCH: семпл прискорюється чи сповільнюється під довжину, як FIT TO у семплера (разом із висотою, без time-stretch). AS IS: грає зі своєю швидкістю й обрізається на межі з коротким згасанням.
Де працює: у ряді FILLS на TRACK (блок філа жовтий, як зараз; край блока = LENGTH, тягнеться з прив'язкою до долей) і кнопка FILL на LIVE (стартує на найближчій долі так, щоб закінчитися на такті, як інші філи). Семпл вибирається тим самим рядком SAMPLE і тим самим браузером (типово відкривається тип FX / теги FILL).
