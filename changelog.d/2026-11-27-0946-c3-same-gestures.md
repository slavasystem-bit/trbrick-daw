## Stage C3 part 1: every knob follows the same gestures (UI-2, UI-3)

- Instrument block cells (`ParamCell`): Shift while dragging = finer (x0.1), Option+click = the default (a new track's mixer values, a new kick, a new sample edit, a new patch for the same engine; the ENGINE row is not reset), one undo step; the gestures are named in the info line. `FloatCell` takes the default; `PatchCell` steps to the default.
- The PITCH fader and MIX LAB LEVEL / PAN are `ValueField` bars: a drag moves from the current value (a click no longer jumps), Shift finer, Option+click = 0 % / 80 % / centre, double click = type, Esc during a drag puts it back.
